## 0. 总结

```
闭包 = 函数 + 函数定义时的作用域
作用：让函数继续访问外层变量
常见用途：保存状态、封装私有变量
注意：不再使用时解除引用，避免长期占用内存
```

## 1. 什么是闭包

> 内部函数访问外部函数的变量，并被外部使用时，就形成了闭包。

```js
function createCounter() {
  let count = 0;

  return function () {
    return ++count;
  };
}

const counter = createCounter();

counter(); // 1
counter(); // 2
```

`createCounter` 已经执行结束，但返回的函数仍然引用 `count`，
所以 `count` 不会被回收。

## 2. 原理

函数在定义时会记录外层作用域。
以后无论在哪里调用，都会沿着定义时的作用域链查找变量。

```
counter → createCounter 作用域 → 全局作用域
```

## 3. 作用

- 保存函数执行后的状态。
- 封装私有变量，避免被外部直接修改。
- 在回调函数中保留外层数据。

## 4. 注意

闭包本身不是内存泄漏。
只有闭包被长期引用时，它所引用的变量才会一直保留。

```js
let counter = createCounter();

counter = null; // 不再使用时解除引用
```

## 5. 例子
```js
function greet(greeting) {
  return function (name) {
    console.log(`${greeting}, ${name}!`);
  };
}

const sayHello = greet("Hello");
const sayHi = greet("Hi");

sayHello("Alice");                       // Hello, Alice!
sayHi("Bob");                            // 输出: Hi, Bob!
```

```js
let i;
for (i = 0; i < 4; i++) {
  setTimeout(() => {
    console.log(i);
  }, 100);
}
// 4 4 4 4
// 立即执行函数绑定当前作用域的i
```

```jsx

function Counter() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    const timer = setInterval(() => {
      setCount(count + 1);
    }, 1000);

    return () => clearInterval(timer);
  }, []);

  return <div>{count}</div>;
}
// 0

```
