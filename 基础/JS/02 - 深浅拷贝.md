## 0. 总结

> 实现状态不可变性。

```
基本类型赋值：复制值，互不影响
数组和对象赋值：复制引用，指向同一份数据
浅拷贝：只复制第一层
深拷贝：递归复制所有层
```

## 1. 值拷贝

> 基本类型赋值：复制值，互不影响
> 引用类型赋值：复制引用，指向同一份数据


## 2. 浅拷贝

> 浅拷贝只创建新的外层，嵌套的数组或对象仍然共享引用。

- 数组：`[...arr]`、`slice()`
- 对象：`{ ...obj }`、`Object.assign({}, obj)`

```js
const obj = { info: { value: 1 } };
const copy = { ...obj };

obj === copy; // false
obj.info === copy.info; // true
```

## 3. 深拷贝

> 深拷贝会复制所有层级，嵌套数据也不再共享引用。

```js
// 1. 手写
// 边界条件：非对象或 null，直接返回
// 递归处理
function deepClone(obj) {
  // 数组包含在里面
  if (typeof obj !== "object" || obj === null) {
    return obj;
  }

  const copy = Array.isArray(obj) ? [] : {};

  for (const key in obj) {
    if (obj.hasOwnProperty(key)) {
      copy[key] = deepClone(obj[key]);
    }
  }

  return copy;
}

// 2. deepClone() lodash库

// 3. JSON 序列化
// 它无法正确处理undefined、函数、循环引用等特殊数据。

JSON.parse(JSON.stringify(obj));

// 4. structuredClone() 内置

const copy = structuredClone(obj);

obj.info === copy.info; // false
```
