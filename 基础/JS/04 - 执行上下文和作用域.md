## 0. 总结

```
执行上下文：代码运行时创建的环境
作用域：变量能够被访问的范围
作用域链：当前作用域找不到变量时，逐层向外查找
调用栈：管理执行上下文，后调用的函数先执行完
```

## 1. 执行上下文

> 全局代码和函数执行时，都会创建对应的执行上下文。

执行上下文分为两个阶段：

1. 创建阶段：确定 `this`，处理函数、变量声明。
2. 执行阶段：执行代码，进行赋值和函数调用。

```js
console.log(a); // undefined

var a = 1;
```

创建阶段已经声明了 `a`，并将它初始化为 `undefined`；
执行到赋值语句时，`a` 才变成 `1`。

函数调用时，新的函数执行上下文会进入调用栈；
函数执行结束后，该执行上下文出栈。

## 2. 作用域

> 作用域在代码定义时确定，决定变量在哪里可以被访问。

```
全局作用域：整个程序都可以访问
函数作用域：函数内部可以访问
块级作用域：只在 {} 内可以访问
```

`var` 是函数作用域，`let` 和 `const` 是块级作用域。

```js
function outer() {
  const name = 'Tom';

  function inner() {
    console.log(name);
  }

  inner();
}
```

## 3. 作用域链

变量查找从当前作用域开始，找不到就逐层向外查找，
直到全局作用域。不能从外层访问内层变量。

```
当前作用域 → 外层作用域 → 全局作用域
```

## 4. 两者的区别

```
作用域：代码定义时确定，描述变量的可见范围
执行上下文：代码运行时创建，保存当前运行状态
```
