
## 0. 总结

```
1. 增删元素：push、pop、unshift、shift
2. 遍历数组：forEach、map、flatMap、filter、reduce
3. 查找元素：includes、indexOf、lastIndexOf、find、findIndex
4. 条件判断：some、every
5. 截取和修改：slice、splice、toSpliced
6. 拼接和转换：concat、join、[...arr]
7. 排序和反转：sort、reverse、toSorted、toReversed
8. 数组扁平化：flat
9. 创建和判断数组：Array.isArray、Array.from、Array.of、new Array
```

## 1. 增删元素

```js
const arr = [1, 2, 3];

// 1. push
// 在尾部添加元素，修改原数组，返回新长度。
arr.push(4); // 4
console.log(arr); // [1, 2, 3, 4]

// 2. pop
// 删除尾部元素，修改原数组，返回被删除的元素。
arr.pop(); // 4
console.log(arr); // [1, 2, 3]

// 3. unshift
// 在头部添加元素，修改原数组，返回新长度。
arr.unshift(0); // 4
console.log(arr); // [0, 1, 2, 3]

// 4. shift
// 删除头部元素，修改原数组，返回被删除的元素。
arr.shift(); // 0
console.log(arr); // [1, 2, 3]
```

## 2. 遍历数组

```js
const arr = [1, 2, 3];

// 1. forEach
// 只遍历数组，不返回新数组。
arr.forEach((item, index) => {
  console.log(item, index);
});

// 2. map
// 处理每个元素，返回新数组。
const map = arr.map((item) => item * 2);
// [2, 4, 6]

// 3. flatMap
// 先执行 map，再把结果扁平化一层。
const flatMap = arr.flatMap((item) => [item, item * 2]);
// [1, 2, 2, 4, 3, 6]

// 4. filter
// 筛选满足条件的元素，返回新数组。
const filter = arr.filter((item) => item > 1);
// [2, 3]

// 5. reduce
// 把整个数组累计计算成一个结果。
const reduce = arr.reduce((accumulator, current) => {
  return accumulator + current;
}, 0);
// 6
```

## 3. 查找元素

```js
const arr = [10, 20, 30, 20];

// 1. includes
// 判断数组是否包含某个元素，返回 boolean。
arr.includes(20); // true

// 2. indexOf
// 从前往后查找元素，返回下标，找不到返回 -1。
arr.indexOf(20); // 1

// 3. lastIndexOf
// 从后往前查找元素，返回下标，找不到返回 -1。
arr.lastIndexOf(20); // 3

// 4. find
// 返回第一个满足条件的元素，找不到返回 undefined。
const find = arr.find((item) => item > 15);
// 20

// 5. findIndex
// 返回第一个满足条件元素的下标，找不到返回 -1。
const findIndex = arr.findIndex((item) => item > 15);
// 1
```

## 4. 条件判断

```js
const arr = [1, 2, 3];

// 1. some
// 判断是否至少有一个元素满足条件。
arr.some((item) => item > 2); // true

// 2. every
// 判断是否所有元素都满足条件。
arr.every((item) => item > 1); // false
```

## 5. 截取和修改

```js
const arr = [1, 2, 3, 4];

// 1. slice
// 截取数组的一部分，不修改原数组，返回新数组。
// 范围是 [start, end)。
const slice = arr.slice(1, 3);
// [2, 3]

console.log(arr);
// [1, 2, 3, 4]

// 2. splice
// 删除、添加或替换元素。
// 会修改原数组，返回被删除的元素。
const removed = arr.splice(1, 2, 10, 20);

console.log(removed);
// [2, 3]

console.log(arr);
// [1, 10, 20, 4]

// 3. toSpliced
// 功能和 splice 类似，但不会修改原数组，返回新数组。
const newArr = [1, 2, 3, 4].toSpliced(1, 2, 10);

console.log(newArr);
// [1, 10, 4]
```

## 6. 拼接和转换

```js
const arr1 = [1, 2];
const arr2 = [3, 4];

// 1. concat
// 拼接数组，不修改原数组，返回新数组。
const concat = arr1.concat(arr2);
// [1, 2, 3, 4]

// 2. 展开运算符
// 拼接数组，不修改原数组，返回新数组。
const spread = [...arr1, ...arr2];
// [1, 2, 3, 4]

// 3. join
// 把数组中的元素连接成字符串。
const join = ['a', 'b', 'c'].join('-');
// "a-b-c"
```

## 7. 排序和反转

```js
const arr = [10, 2, 30];


// 1. sort
// 对数组进行排序，会修改原数组。
// 默认会先把元素转换成字符串，再按照字符顺序排序。升序：a - b
arr.sort((a, b) => a - b);
// [2, 10, 30]

// 2. reverse
// 反转数组，会修改原数组。
arr.reverse();
// [30, 10, 2]

// 3. toSorted
// 对数组排序，不修改原数组，返回新数组。
const sorted = arr.toSorted((a, b) => a - b);
// [2, 10, 30]

// 4. toReversed
// 反转数组，不修改原数组，返回新数组。
const reversed = arr.toReversed();
// [2, 10, 30]
```

## 8. 数组扁平化

```js
const arr = [1, [2, 3], [4, [5]]];

// 1. flat
// 把嵌套数组展开，默认展开一层。
const flat = arr.flat();
// [1, 2, 3, 4, [5]]

// 指定展开层数。
const flatDeep = arr.flat(2);
// [1, 2, 3, 4, 5]

// 展开所有层级。
const flatAll = arr.flat(Infinity);
// [1, 2, 3, 4, 5]
```

Array.isArray([1, 2, 3]); // true
