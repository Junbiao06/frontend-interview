## 有哪些？

```
1. 基本数据类型：string、number、boolean、undefined、null、symbol、bigint
2. 引用类型数据：object。例如普通对象、数组、日期、正则等。函数本质上也是对象。
```

## 判断方法
### 1. `typeof`

> `typeof` 主要适合判断基本数据类型。
> 优点是简单，并且不会因为变量值为 `null` 而报错
> 缺点是无法区分数组、普通对象、日期等具体的对象类型。

```js
typeof 'hello'       // "string"
typeof 123           // "number"
typeof true          // "boolean"
typeof undefined     // "undefined"
typeof Symbol()      // "symbol"
typeof 10n           // "bigint"

// 特殊
typeof function (){} // "function"
typeof []            // "object"
typeof {}            // "object"
typeof null          // "object"
typeof NaN           // "number"
```

### 2. `instanceof`

> `instanceof` 主要用于判断一个对象的原型链上，是否存在某个构造函数的 `prototype`。
> `instanceof` 左边必须是对象，右边一般是构造函数。


```js
[] instanceof Array         // true 
{} instanceof Object        // true
new Date() instanceof Date  // true


'hello' instanceof String // false
```

### 3. `Object.prototype.toString.call()`

> 准确判断对象的具体类型

```js
Object.prototype.toString.call([])          // "[object Array]"
Object.prototype.toString.call({})          // "[object Object]"
Object.prototype.toString.call(null)        // "[object Null]"
Object.prototype.toString.call(new Date())  // "[object Date]"

```

### 4. 判断数组、`null`和`NaN` 用特定方法

```
Array.isArray(value)
value === null
Number.isNaN(value)
```

### 总结
- 判断基本类型，使用 `typeof`。
- 判断是否为 `null`，使用 `value === null`。
- 判断数组，使用 `Array.isArray`。
- 判断某个类的实例，使用 `instanceof`。
- 判断完整、具体的数据类型，使用 `Object.prototype.toString.call`。
- 判断 `NaN`，使用 `Number.isNaN`。
