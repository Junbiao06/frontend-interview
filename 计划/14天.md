## 五、你最终必须能讲清楚的两个项目主线

### co-docs-editor

```
Clerk 用户认证
  → Next.js 服务端鉴权
  → Convex 查询文档和权限
  → Liveblocks 鉴权并进入 Room
  → Tiptap + Liveblocks 实现实时编辑、评论和协同
```

重点讲：

- 为什么使用 Convex 保存文档元数据。
- 为什么使用 Liveblocks 做实时协同。
- 为什么进入 Liveblocks 房间前还要再校验 Convex 权限。
- Tiptap、Zustand、Liveblocks 三者如何配合。
- 如何处理富文本链接和图片安全。
- 如何处理多人编辑、离线支持和布局同步。

### EMS

```
登录
  → JWT 返回 Token
  → LocalStorage 保存 Token
  → Axios 请求拦截器注入 Bearer Token
  → Express protect 校验身份
  → protectAdmin 校验角色
  → Controller 查询 MongoDB
```

重点讲：

- JWT 和 RBAC 的区别。
- 为什么员工不能直接用 `userId` 查询其他员工数据。
- `bcrypt` 为什么不能保存明文密码。
- `asyncHandler` 和统一错误处理中间件的作用。
- Inngest 如何执行自动签退。
- 为什么定时任务必须显式处理北京时间。
- 失败清理和数据库事务的区别。
