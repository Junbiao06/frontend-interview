下一题考察 React 状态更新和闭包：

```tsx
function Counter() {
  const [count, setCount] = useState(0);

  const handleClick = () => {
    setCount(count + 1);
    setCount(count + 1);

    Promise.resolve().then(() => {
      setCount(count + 1);
    });

    setTimeout(() => {
      setCount(count + 1);
    }, 0);
  };

  return (
    <>
      <p>{count}</p>
      <button onClick={handleClick}>+1</button>
    </>
  );
}
```

点击一次按钮后，最终页面显示多少？为什么？

如果产品要求点击一次最终增加 4，应该如何修改？


点击一次后，最终显示：

```
1
```

因为 `handleClick` 执行时闭包中的 `count` 仍然是初始值 `0`。

四次更新实际上都是：

```
setCount(0 + 1);
```

React 会把它们当成把状态设置为 `1`，而不是连续累加。前两次同步更新会被批处理，Promise 和定时器中的回调虽然稍后执行，但它们捕获的仍然是旧的 `count`。

如果要求点击一次最终增加 4，应该使用函数式更新：

```
const handleClick = () => {
  setCount((count) => count + 1);
  setCount((count) => count + 1);

  Promise.resolve().then(() => {
    setCount((count) => count + 1);
  });

  setTimeout(() => {
    setCount((count) => count + 1);
  }, 0);
};
```

函数式更新会基于 React 队列中最新的状态依次计算，因此最终结果是 `4`。不过由于后两次更新分别在微任务和宏任务中，页面可能先显示中间结果，等定时器执行后最终变为 `4`。
