
## 回溯算法总结

回溯本质上就是：

> 递归枚举所有可能，发现不合适就撤销选择，回到上一层继续试别的选择。

可以理解成一句话：

```
做选择 -> 递归 -> 撤销选择
```


```js
const backtrack = (路径, 选择列表) => {
  // 1. 递归出口：什么时候收集答案
  if (满足结束条件) {
    res.push(路径);
    return;
  }

  // 2. 枚举当前层所有选择
  for (let 选择 of 选择列表) {
    // 3. 剪枝：不合法就跳过
    if (不合法) continue;

    // 4. 做选择
    路径.push(选择);

    // 5. 进入下一层
    backtrack(路径, 新的选择列表);

    // 6. 撤销选择
    路径.pop();
  }
};
```
